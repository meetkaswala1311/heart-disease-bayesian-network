# Heart Disease Diagnosis using Bayesian Network

Implementation of a Bayesian Network for medical diagnosis using the standard Heart Disease dataset (`heart.csv`).

## 📋 Overview
- **Objective:** Construct a Bayesian Network using clinical attributes (Age, Sex, Chest Pain, Max Heart Rate, Exercise Angina, ST Depression/Oldpeak) to predict and diagnose Heart Disease (AHD).
- **Libraries Used:** `pgmpy`, `pandas`, `scikit-learn`, `numpy`, `matplotlib`, `seaborn`, `networkx`.
- **Metrics Evaluated:** Accuracy, Precision, Recall, Confusion Matrix, and Classification Report.

## 📁 Repository Structure
- `question_2_bayesian_network.py` - Complete standalone Python script.
- `Question_2_Heart_Disease_Bayesian_Network.ipynb` - Interactive Jupyter Notebook walkthrough.
- `heart.csv` - Clinical dataset for training and testing.
- `requirements.txt` - Project dependencies.

## 🚀 Setup & Run

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run Python script:**
   ```bash
   python question_2_bayesian_network.py
   ```

3. **Or launch Jupyter Notebook:**
   ```bash
   jupyter notebook Question_2_Heart_Disease_Bayesian_Network.ipynb
   ```
